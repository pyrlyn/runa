# Аудіо, відео та зір

Три маршрути, які ніколи не змішуються мовчки (D12):

| Маршрут | Локально | OpenAI | Anthropic |
|-------|-------|--------|-----------|
| **native** | mtmd + mmproj для аудіо/зору | `input_audio` на моделях з підтримкою аудіо | недоступно |
| **asr** | whisper.cpp (`whisper-rs`) → текст у промпті | транскрипт у промпті | транскрипт у промпті |
| **auto** | native, якщо є mmproj (аудіо) / VL mmproj (зір); інакше ASR | `input_audio`, якщо модель підтримує, інакше транскрипт | транскрипт |

## Аудіо (`--audio`, `--audio-route`)

Пріоритет: CLI `--audio-route` > `RUNA_AUDIO_ROUTE` > `[audio] route` > `auto`.

- **native** без аудіо-mmproj (або на Anthropic / OpenAI-моделі без аудіо) завершується помилкою.
- **asr** завжди транскрибує (`runa media transcribe` використовує той самий рушій).
  Файли ggml Whisper `base` і `large-v3-turbo` закріплено за SHA-256 і розміром
  (заголовки Hugging Face `x-linked-etag` / `x-linked-size`). Silero VAD необов'язковий
  і обмежений за розміром; якщо файлу немає, використовується енергетичний VAD.
  Parakeet-TDT поки недоступний.
- PCM — 16 kHz моно f32 (`runa-media`). Нативний маршрут OpenAI загортає WAV у base64.

Сусідній файл `*mmproj*.gguf` підхоплюється лише тоді, коли він потрібен нативному аудіо або `--image`/`--video`.
`--mmproj`, якщо задано, має перевагу.

## Зір (`--image`, `--video`)

Лише локально, функція `mtmd` + mmproj для зору:

- `--image PATH` (можна повторювати) — статичні зображення, медіамаркери, без часових міток.
- `--video PATH` — `runa-media` вибирає ≤ 32 кадри; кожен стає бітмапом mtmd
  з маркером `[t=12.0s]` у промпті.

Хмарні `--image`/`--video` у `runa run openai:…` — явна помилка (використайте
локальну VL-модель або адаптери P4.7 із `serve`).

## Вибірка кадрів відео

Рівномірна + за зміною сцени (L1 гістограми), не більше 32, зі зміною розміру. ffmpeg у PATH або
`ffmpeg-sidecar`. Див. P4.5.

## Fit

Кадри × токени на кадр + секунди аудіо враховуються як контекст; байти mmproj розміщуються
на GPU. Переповнення → `NO FIT`, код виходу 2 (`docs/fit.md`).
